# Security Policy

## Supported versions

Security fixes are developed against the latest commit on the default branch. Older commits and release archives are not guaranteed to receive backported fixes.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting feature from the repository's **Security** tab when it is available. If private reporting is not enabled, contact the repository maintainer through GitHub and request a private disclosure channel before sending technical details.

Include the affected workflow or file, the impact, reproduction steps, and any suggested mitigation. Avoid including real credentials, personal data, or live exploit payloads in reports.

## Response

The maintainer will make a best effort to acknowledge reports within seven days, investigate the issue, and coordinate a fix and disclosure timeline with the reporter. This is a volunteer-maintained demonstration repository; no guaranteed response or remediation SLA is offered.
